## Overview

**Modern Admin Panel** is a web-based dashboard project designed to provide a clean foundation for modern administrative interfaces. Built with Nuxt 3 and Vue.js, it leverages a component-based architecture to support organized development and future extensibility.

The project aims to combine a modern interface with a maintainable codebase, making it a foundation for building and extending web-based management applications.

## Tech Stack

* **[Nuxt 3](https://nuxt.com/)** — Vue.js framework for modern web applications
* **[Vue.js](https://vuejs.org/)** — Component-based frontend development
* **[Node.js](https://nodejs.org/)** — JavaScript runtime
* **[npm](https://www.npmjs.com/)** — Package management

## Getting Started

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/) — A version compatible with the project's dependencies
* npm — Included with Node.js

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Hosein-NZF/modern-admin-panel.git
   ```

2. Navigate to the project directory:

   ```bash
   cd modern-admin-panel
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal, typically:

   ```text
   http://localhost:3000/modern-admin-panel/
   ```

### Production Build

Build the application for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Project Goals

* Maintain a clean and organized frontend codebase.
