## Overview

Modern Admin Panel is a frontend project designed to provide a foundation for building modern administrative interfaces. Built with Nuxt 3 and Vue.js, it follows a component-based approach to keep the codebase organized, maintainable, and easy to extend.

## Tech Stack

* **[Nuxt 3](https://github.com/iman3212)** — Vue.js application framework
* **[Vue.js](https://github.com/iman3212)** — Reactive, component-based UI development
* **[Node.js](https://github.com/iman3212)** — JavaScript runtime
* **[npm](https://github.com/iman3212)** — Dependency management

## Getting Started

### Prerequisites

* Node.js
* npm

### Installation

Clone the repository:

```bash
git clone https://github.com/iman3212/Modern-Admin-Panel.git
cd Modern-Admin-Panel
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal.

### Production Build

Build the application:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
